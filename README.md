# Система управління таксі-сервісом

Консольний додаток для управління таксі-сервісом, що реалізує основні функції для користувачів, водіїв, замовлень та поїздок.

## Опис системи

Система таксі-сервісу дозволяє:
- Реєструвати нових користувачів та водіїв
- Створювати замовлення таксі
- Відстежувати та змінювати статуси замовлень
- Призначати водіїв на замовлення
- Розраховувати та проводити оплату поїздок
- Завершувати поїздки та оцінювати водіїв
- Переглядати звіти про користувачів та водіїв

## Структура проекту

```
├── main.py                 # Головний файл програми з меню
├── program_clases/         # Директорія з основними класами
│   ├── user.py             # Клас User для управління користувачами
│   ├── driver.py           # Клас Driver для управління водіями
│   ├── order.py            # Клас Order для управління замовленнями
│   ├── ride.py             # Клас Ride для управління поїздками
├── validators.py           # Функції валідації введених даних
├── users.json              # Файл для зберігання даних користувачів
├── drivers.json            # Файл для зберігання даних водіїв
├── orders.json             # Файл для зберігання даних замовлень
├── rides.json              # Файл для зберігання даних поїздок
```


### Інструкція для запуску
1. Клонуйте репозиторій або завантажте файли проекту
4. Запустіть програму командою:

## Інструкція з використання

### 1. Головне меню програми
При запуску програми відображається головне меню.

### 2. Реєстрація користувача
- Виберіть опцію "1" в головному меню
- Введіть ім'я користувача
- Введіть номер телефону у форматі "+380xxxxxxxxx"
- Після успішної реєстрації користувачу автоматично надається баланс 1000 грн

### 3. Реєстрація водія
- Виберіть опцію "2" в головному меню
- Введіть ім'я водія
- Введіть номер телефону у форматі "+380xxxxxxxxx"
- Введіть модель автомобіля
- Після реєстрації водію призначається початковий рейтинг 0.0

### 4. Створення замовлення
- Виберіть опцію "3" в головному меню
- Виберіть користувача зі списку (введіть номер користувача)
- Введіть початкову адресу
- Введіть кінцеву адресу
- Замовлення створюється з поточним часом і статусом "новий"

### 5. Зміна статусу замовлення
- Виберіть опцію "4" в головному меню
- Виберіть замовлення зі списку активних замовлень
- Виберіть новий статус замовлення.
- При зміні статусу на "в процесі":
  - Необхідно вибрати водія
  - Система розраховує ціну поїздки (базовий тариф 100 грн)
  - Перевіряється баланс користувача
  - Створюється нова поїздка
  - Знімаються кошти з рахунку користувача

### 6. Завершення поїздки
- Виберіть опцію "5" в головному меню
- Введіть ID поїздки для завершення
- Поїздка завершується з поточним часом
- Оцініть водія за шкалою від 1 до 5
- Рейтинг водія оновлюється
- Статус відповідного замовлення змінюється на "завершений"

### 7. Перегляд звіту водія
- Виберіть опцію "6" в головному меню
- Введіть ID водія
- Відображається детальний звіт про водія:
  - Основна інформація (ім'я, авто, телефон, рейтинг)
  - Історія поїздок з деталями
  - Загальний заробіток водія

### 8. Перегляд звіту користувача
- Виберіть опцію "7" в головному меню
- Введіть ID користувача
- Відображається детальний звіт про користувача:
  - Основна інформація (ім'я, телефон, ID, баланс)
  - Історія поїздок з деталями
  - Загальна сума витрат

### 9. Завершення роботи програми
- Виберіть опцію "0" в головному меню
